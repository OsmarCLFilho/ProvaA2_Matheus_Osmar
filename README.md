# Prova A2 - Matheus e Osmar

O projeto é composto por um backend _ASP.NET_ utilizando _Minimal API_ e um banco de dados _SQLite_ gerenciado através de modelos.

O objetivo é realizar operações CRUD sobre folhas de pagamento.

## Endpoints
- `POST /api/folha/cadastrar`
- `GET /api/folha/listar`
- `GET /api/folha/buscar/{cpf}/{mes}/{ano}`
- `DELETE /api/folha/remover/{cpf}/{mes}/{ano}`
- `GET /api/folha/total-liquido`
